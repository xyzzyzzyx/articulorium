About Articulorum

Articulorum is a W3C Linked Data Platform with Fedora Commons compatible extensions: versions (Memento), fixity checks and search, on an OCFL storage layer.

This interface lets you:

  • browse containers and resources, with their properties and children;
  • create basic, direct and indirect containers and upload binaries;
  • edit properties with SPARQL Update, replace and download binary content;
  • create, list and view versions, and check the fixity of binaries;
  • delete resources and search the repository.
