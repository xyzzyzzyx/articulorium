Linked Data Platform for Digital Libraries

Articulorium provides a complete solution for building digital libraries with Linked Data principles. Built on Spring Boot 4.1 and Spring Cloud 2025.1.

View on GitHub

Key Features

W3C LDP 1.0 Compliance

Full implementation of the Linked Data Platform specification with Fedora Commons compatible extensions.

OCFL Storage Layer

Uses Oxford Common File Layout for versioned storage on local file system or S3-compatible object stores.

Web Access Control

Full implementation of Web Access Control (acl:Read/Write/Append/Control) with support for OpenID Connect.

Digital Library Structures

Support for communities, sub-communities, collections and PCDM topologies.

IIIF Export

Export of digital objects as IIIF Presentation 3.0 manifests and collections.

AI Integration

Optional Spring AI agent for topology suggestions, metadata extraction, topic modeling and record classification.

OAI-PMH Support

Full OAI-PMH 2.0 data provider with Dublin Core mappings and hierarchical sets.

Harvesting

Harvests from OAI-PMH, DSpace, Fedora Commons and VIVO repositories into the platform.

Internationalization

Built-in support for 12 languages with locale resolution and translation management.

Activity Streams 2.0

Support for W3C Activity Streams 2.0 for tracking resource changes and user activities.

Search & Discovery

Powerful search capabilities with Solr integration and discovery layer.

Triplestore Integration

SPARQL 1.1 store (QLever) for semantic querying of the platform data.

Architecture

Articulorium is built as a collection of microservices using Spring Cloud Consul and Kafka for service discovery, configuration and messaging.

Service Overview

The system architecture consists of:

  • Gateway: Central entry point routing requests to services
  • Platform: Core LDP server with RDF storage and Web Access Control
  • UI: Angular single-page application for user interaction
  • Discovery UI: Server-rendered public discovery layer with Mirador
  • Transform: Service for converting resources to search documents and IIIF exports
  • Topology: PCDM topologies and resource building capabilities
  • OAI-PMH: OAI-PMH 2.0 data provider service
  • Harvest: Service for harvesting repositories into the platform
  • AI Agent: Optional Spring AI agent for topology suggestions and metadata extraction

Core Modules

The LDP server with RDF sources, containers, files, versions, fixity and search.

Angular single page application user interface.

Server-rendered public discovery layer with Angular SSR and Mirador.

transform

Resource transformation service for search documents and IIIF exports.

PCDM topologies and building resources in the platform.

OAI-PMH 2.0 data provider service.

harvest

Service for harvesting repositories into the platform.

ai

Optional Spring AI agent service.

LDP resource model, vocabularies, IRI and N-Triples helpers (no framework dependencies).

Spring Cloud Bus events and Spring Integration flows that dispatch them.

activitystreams

W3C Activity Streams 2.0 types, object model, JSON serialization and validation.

agent

i18n-spring-boot-starter

Shipped locales, locale resolution and message bundles for every service.

Serves the UI and its support API (settings, agents from articulorium.agents.definitions).

Keeps a Solr collection in sync with the platform.

triplestore

Mirrors every resource into a SPARQL 1.1 store (QLever).

Getting Started

Quick Start with Docker Compose

Articulorium can be run locally using Docker Compose:

docker compose up --build

After starting, access the application at:

  • User Interface: http://localhost:8000/ui/
  • Discovery Layer: http://localhost:8000/discover/
  • LDP Root: http://localhost:8000/platform/
  • Swagger UI: http://localhost:8000/swagger-ui.html
  • Keycloak: http://localhost:8000/auth/
  • Admin Console: http://localhost:8000/auth/admin/ (login with admin / admin)

Development Setup

For development, you can build and test with Maven:

mvn verify

Demo Users

When running locally, use these demo users for testing:

  • Curator: curator / curator (editors role)
  • Administrator: administrator / administrator (editors and administrators roles)
  • Reader: reader / reader (no special roles)

API Documentation

Articulorium exposes several APIs through its services. All APIs are accessible through the gateway at http://localhost:8000:

Gateway Swagger UI

The main API documentation is available through a single Swagger UI that aggregates all services:

  • Swagger UI: http://localhost:8000/swagger-ui.html

Platform API

The LDP server provides a full Linked Data Platform implementation:

  • Base URL: http://localhost:8000/platform/
  • Documentation: OpenAPI Spec

Transform Service

For IIIF exports and search document transformations:

  • Base URL: http://localhost:8000/transform/
  • IIIF Exports: GET /transform/iiif/<path>

Topology Service

For working with PCDM topologies:

  • Base URL: http://localhost:8000/topology/

OAI-PMH Service

For harvesting records with OAI-PMH:

  • Base URL: http://localhost:8000/oai?verb=...

AI Agent Service

Optional AI capabilities:

  • Base URL: http://localhost:8000/ai/capabilities
